`mend` applies AI-written edits to a text file tree. It implements the `SPEC.md` contract for unified diffs, SEARCH/REPLACE blocks, V4A patches, and JSON edits, with atomic apply semantics.

## Run it

```sh
node main.ts --format=auto patch.diff
```
